# 野怪战斗计算 v0.8.0

在游戏选中野怪、野怪棋盘加载完成且战斗尚未开始时，右侧 `Monster Combat`
系统会在野怪棋盘稳定 1 秒后自动计算，并把胜负与胜率悬浮显示在野怪头像上方。
面板的 `CALCULATE` 按钮仍然保留，可用于强制重算。

计算输入直接来自游戏当前权威状态：

- 玩家物品、技能、英雄属性与当前生命；
- 野怪物品、技能、英雄类型、生命及其他战斗属性；
- 物品实例 ID、模板 ID、品质、附魔、尺寸、槽位、标签和运行时属性。

点击后会冻结 `monster-input-时间戳.json`，避免实时导出在 Monte Carlo 运行期间
改变输入。独立战斗进程执行 21 至 101 个样本；达到统计置信条件会提前停止，单场最多
模拟 2400 tick。

面板显示：

- 玩家胜率；
- 玩家胜 / 野怪胜 / 平局次数；
- 实际样本数；
- `win`、`loss` 或低置信度结果；
- 未支持规则的执行次数。

如果计算完成前玩家、野怪、时间或遭遇发生变化，结果标记为 `[STALE]`。战斗开始后
按钮关闭，因为此时结果已不再能用于战前决策。

输出位于 `BepInEx/config/BazaarLab/`：

- `monster-input-*.json`：不可变计算输入；
- `monster-result-*.json`：完整预测结果。
